Recommendation: Keep client (the default). It's simpler, more reliable for debugging, and perfect for your standalone Spark cluster in Docker Compose.
If you ever need cluster mode, just change it to cluster here (or via Extra JSON).
Spark Binary (showing default "spark_submit")
This is the command Airflow uses to submit jobs.
    • Default: spark-submit (or sometimes shown as "spark_submit") 
    • In your custom image (from the Dockerfile I provided), spark-submit is already in $PATH (via ENV PATH=${SPARK_HOME}/bin:${PATH}). 
You usually don't need to change this. It will automatically use the spark-submit from /opt/spark/bin/.
If for some reason it's not found, you can override it in the connection's Extra field:
JSON
{
  "spark_binary": "spark-submit"
}
(or full path: /opt/spark/bin/spark-submit)
Full Recommended Connection (via UI or Environment Variable)
In Airflow UI (Admin → Connections → Create):
    • Conn Id: spark_default 
    • Conn Type: Spark 
    • Host: spark://spark-master 
    • Port: 7077 
    • Deploy Mode: client (default) 
    • (Leave Spark Binary blank or spark-submit) 
Extra (optional JSON – only if you need overrides):
JSON
{
  "queue": "default",
  "deploy_mode": "client",
  "spark_binary": "spark-submit"
}
Or via environment variable (in docker-compose under airflow-common environment):
YAML
AIRFLOW_CONN_SPARK_DEFAULT: 'spark://spark-master:7077?deploy_mode=client'

----Dockerfile custom image

# ============================
# Airflow + Spark Custom Image
# Base: Apache Airflow 2.11.0 (Python 3.9)
# ============================
FROM apache/airflow:2.11.0-python3.9

# Build arguments for UID/GID alignment with host
ARG HOST_UID=50000
ARG HOST_GID=0

# Switch to root for system installations
USER root

# -----------------------------
# 1. System Dependencies
# -----------------------------
RUN apt-get update && \
    apt-get install -y --no-install-recommends \
        # Core utilities
        curl \
        ca-certificates \
        procps \
        iproute2 \
        net-tools \
        # ODBC & FreeTDS for SQL Server
        unixodbc \
        unixodbc-dev \
        freetds-dev \
        freetds-bin \
        freetds-common \
        libsybdb5 \
        tdsodbc \
        # Java for Spark
        openjdk-17-jre-headless \
        # Build tools (for some Python wheels if needed)
        build-essential \
        gcc \
        g++ && \
    apt-get clean && \
    rm -rf /var/lib/apt/lists/*

# -----------------------------
# 2. Microsoft ODBC Driver 17 for SQL Server (recommended over FreeTDS for modern MSSQL)
# -----------------------------
RUN curl -sSL https://packages.microsoft.com/keys/microsoft.asc | apt-key add - && \
    curl -sSL https://packages.microsoft.com/config/debian/12/prod.list > /etc/apt/sources.list.d/mssql-release.list && \
    apt-get update && \
    ACCEPT_EULA=Y apt-get install -y --no-install-recommends msodbcsql17 mssql-tools18 && \
    apt-get clean && \
    rm -rf /var/lib/apt/lists/* && \
    echo 'export PATH="$PATH:/opt/mssql-tools18/bin"' >> /etc/profile.d/mssql-tools.sh

# -----------------------------
# 3. Configure FreeTDS (fallback/legacy support)
# -----------------------------
RUN echo "[FreeTDS]\n\
Description = FreeTDS Driver\n\
Driver = /usr/lib/x86_64-linux-gnu/odbc/libtdsodbc.so\n\
Setup = /usr/lib/x86_64-linux-gnu/odbc/libtdsS.so\n\
UsageCount = 1" >> /etc/odbcinst.ini

RUN echo "[global]\n\
tds version = 7.4\n\
client charset = UTF-8\n\
text size = 20971520" > /etc/freetds/freetds.conf

# -----------------------------
# 4. Install Spark Client (for SparkSubmitOperator)
# -----------------------------
ARG SPARK_VERSION=3.5.3
ARG HADOOP_VERSION=hadoop3

ENV SPARK_HOME=/opt/spark
ENV PATH=${SPARK_HOME}/bin:${SPARK_HOME}/sbin:${PATH}
ENV JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64

RUN curl -fSL "https://archive.apache.org/dist/spark/spark-${SPARK_VERSION}/spark-${SPARK_VERSION}-bin-${HADOOP_VERSION}.tgz" \
        -o /tmp/spark.tgz && \
    tar -xzf /tmp/spark.tgz -C /opt && \
    mv "/opt/spark-${SPARK_VERSION}-bin-${HADOOP_VERSION}" "${SPARK_HOME}" && \
    rm /tmp/spark.tgz && \
    chmod -R 755 ${SPARK_HOME}

# Allow Spark to pick up JDBC drivers from mounted volume
ENV SPARK_CLASSPATH=/opt/airflow/sparkFiles/jars/*

# -----------------------------
# 5. Create/Align Airflow User with Host UID/GID
# -----------------------------
RUN if [ "${HOST_GID}" != "0" ]; then \
        groupmod -g ${HOST_GID} airflow || groupadd -g ${HOST_GID} airflow; \
    fi && \
    usermod -u ${HOST_UID} -g ${HOST_GID:-0} airflow || \
    useradd -u ${HOST_UID} -g ${HOST_GID:-0} -m airflow

# Ensure airflow user owns necessary directories
RUN chown -R airflow:0 /opt/airflow && \
    chmod -R g+rwX /opt/airflow

# -----------------------------
# 6. Switch to Airflow User
# -----------------------------
USER airflow

# -----------------------------
# 7. Python Dependencies
# -----------------------------
# Copy requirements early for better layer caching
COPY --chown=airflow:0 requirements.txt /opt/airflow/requirements.txt

# Optional: Add extra Python path for your scripts


ARG PYTHONPATH
ENV PYTHONPATH=/opt/airflow/scripts${PYTHONPATH:+:$PYTHONPATH}

RUN pip install --no-cache-dir --upgrade pip && \
    pip install --no-cache-dir --timeout=1000 -r /opt/airflow/requirements.txt

# -----------------------------
# 8. Final Cleanup & Verification
# -----------------------------
RUN spark-submit --version > /dev/null 2>&1 || echo "Spark not installed properly" && \
    python -c "import pyodbc; print('pyodbc OK')" || echo "pyodbc missing"

# Set default command (overridden by docker-compose)
CMD ["airflow", "version"]
